# Web Application Testing

To test local web applications, write native Playwright / CDP automation scripts.

## Core Capabilities
- Automated route inventory verification
- Visual regression inspection across viewports (Desktop: 1280x800, Mobile: 375x812)
- Dual-theme Light Mode and Dark Mode verification
- Accessibility audit using axe-core / WCAG AA rules
- Console error and network telemetry capture
