## Restored homepage title

**Another AI tool? Sure. Another Subscription? Nope.**

Historical source: `src/pages/HomePage.tsx` immediately before homepage redesign commit `7cfc2a36` (parent `b2f79e1`). The title is rendered with visual line breaks; tests normalize the heading text and assert this exact wording, capitalization, and punctuation.

## Changes

- Refined the homepage hero alignment, width, typography, description, search hierarchy, and collection entry points while retaining its existing sections, links, and functional search.
- Reduced repeated card treatments in the category/resource areas and added restrained Frontier, Free Access, and GitHub Projects accents.
- Tightened desktop navigation spacing, made active groups apparent, and improved keyboard focus and touch-target styles. Desktop and mobile share the same route groups.
- Removed the global ambient glow and the decorative theme hint/arrow. The theme control retains its accessible label, state, and light/dark behavior.
- Refined Frontier Models search/filter controls and collection spacing, and reduced visual weight in the Free Access callout.
- Updated existing tests to assert the restored exact title and current accessible/visual behavior.

No model/access records, GitHub project verification rules, backend/API logic, canonical URLs, SEO metadata, or sitemap logic were changed. The sitemap was regenerated by the build script during verification, then restored to its original tracked contents because those generated URL changes are outside this task.
